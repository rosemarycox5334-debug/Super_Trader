# 第一阶段 · 样张与验收边界

本轮从工作树中已经实现的双主题接续开发，不回滚深色交易台，也不以旧报告的页面数为导航依据。阶段二以用户明确认可本轮桌面样张为起点。

## 视觉决定

- 外观只有一个入口：设置 → 通用 → 外观。启用插件即应用研究配色与品牌；停用即恢复宿主。用户 2026-11-21 明确取消「全局外壳换肤」开关和面板顶部快捷控件，二者不再实现。

- 浅色研究简报：页面 `#F6F7F9`、白色内容面、正文 `#181C23`、交互深蓝 `#173955`。细香槟色只作章节编号后的短线，不是第二种动作色。报价数字采用等宽或 tabular-nums，标题优先 Bahnschrift，中文回退到系统无衬线。本机存在 Bahnschrift 字体文件，其他机器不下载字体。
- 专家选股保留输入、选择专家、已有结果与证据阅读顺序；用细边白色内容面、6–8px 圆角和轻阴影组织，不在整张桌面铺坐标纸。个股结果的层级是名称/代码及证据时间 → 最新价、涨跌及时间口径 → 研究动作。非交易日不把接口访问时间标成交易时间。
- 外壳沿用已接入的宿主令牌、原生设置和面板外观选择。五个非样张板块与独立日报会随共享令牌获得新浅色；本阶段不重排这些板块或改动复盘数据。深色使用接手时的调色板。

## 验收边界

只接受本次 DSH Desktop 安装后的实际窗口截图作为新版样张。接手时 `.out-shots/` 含旧版页面渲染器截图、历史脚本和临时 HTML，不能把它们当作本次新版桌面截图。真实桌面受用户控制时停止操作，允许只读验证，不能用独立浏览器或复制 HTML 补图。行情日期缺失不猜交易日；休市时的 UI 检查不等于在交易时段实测过轮询。样张未获同意前不改变其余页面结构，不推送远程。
