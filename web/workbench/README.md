# Super Agent 投研工作台

入口：[chat_main.html](../../reports/chat_main.html)。双击打开，不需要服务器或前端依赖。

只做这几件事：**Super Agent 对话 + 可插件化改造**、**量化概率**、**专家团队选股**、**自选股批量研判**、**专家操盘记录与复盘**。

## 1. Super Agent：可以被对话改造的工作台

- 首页就是对话，没有仪表盘。
- 说「添加插件 龙虎榜」会真的新增一个插件页；「隐藏插件 专家团队」「删除插件 龙虎榜」同样生效。
- 左侧「管理工作台插件」可以新增、启停、上下排序、删除；状态写入本机 localStorage。
- 内置插件（量化概率、专家团队）只能停用，不能删除；自定义插件是演示槽位，数据源明确标注未接入。
- 支持多会话：新建、切换、导出、删除；草稿与消息刷新后保留。

## 2. 量化概率

- 选标的（6,244 个，可搜索、按类型筛选、分页）。
- 选「未来第 N 根」（1–20）或直接选目标日期：按工作日折算成第几个交易日。
- 输出：该周期的**方向**与**历史同信号命中率**，附预测次数、覆盖率、单边基准。
- 1–20 根概率曲线可点击切换；无信号时显示「无方向信号」并给出基准涨率，不包装成结论。
- 全部数字来自 `probability_grid.json` 的全历史拟合，是内样本频率，不是校准后的未来概率。

## 3. 专家团队（辅助选股）

- 6 位蒸馏专家：巴菲特、段永平、烟蒂股、中性量化、价格行为、成长派；可启停、调权重、改判断依据。
- 选一只标的后，每位专家独立给出「支持 / 反对 / 观望（弃权）」及理由。
- 量化专家读取历史快照；价值类专家在缺少财报/公告时**明确弃权**，不编造理由。
- 共识比例是支持权重占比，不是上涨概率；门槛可调（默认 60%）。

## 4. 自选股（自己挑，批量看）

- 搜索并加入自己关注的标的（最多 200 只），也可以从量化页/专家页一键「加入自选」。
- 按同一持有期批量输出：量化方向、历史命中率、覆盖率、专家共识与「支持 / 观望 / 反对」分布。
- 点开任意一行可展开逐位专家的理由；价值类专家缺数据时弃权。
- 自选与配置一起保存在本机。

## 5. 操盘记录（专家选股 + 买卖 + 复盘）

- 在专家团队或自选股页点「记录操盘」，选择观察/买入/加仓/卖出/清仓，写下当时的理由。
- 保存时会冻结当时的：量化方向与命中率、持有期、逐位专家的投票与理由、配置版本。
- 复盘页对比「当时的信号」与「现在的信号」：方向仍一致 / 已反转 / 消失；买卖方向与量化方向冲突会明确标出。
- 由于没有实时行情，收益按你手动填写的「记录时价格 / 现在价格」计算，并标注这不是账户净值。
- 记录可筛选（全部 / 持仓中 / 已平仓）、按专家筛选、导出 JSON、删除。

## 数据与边界

- `probability_grid.json`：每个标的在 1–20 根上各选一组规则，记录命中率、预测数、方向、覆盖与单边基准。截止 2026-11-05，全历史内样本。
- 内置 4 个样本（中国神华、长江电力、五粮液、宁德时代）的财务数字是演示值；其余标的没有基本面数据。
- 不联网、不调用模型、不存 API 密钥、不下单。插件与配置只保存在本机浏览器。
