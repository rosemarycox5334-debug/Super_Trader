# Super Agent 对话主页

入口：[Super Agent 主页](../../reports/chat_main.html)。打开即与 Super Agent 直接对话，不再先展示仪表盘或常驻配置栏。研究工具折叠为辅助入口；不需要启动服务器或安装前端依赖。

## 已实现的交互

- 主对话：Super Agent 是唯一对话对象，策略专家仅为协作团队；输入代码查询历史快照，筛选信号或发起本地模拟研究。
- 会话历史：新建、切换、导出和删除旧会话；每份对话独立保存消息与未发送草稿，刷新恢复；保留并迁移旧版单一聊天记录。最多保留 30 份，不静默删除旧对话。
- 对话内交付：量化证据卡片、模拟任务进度与结果卡片直接出现在当前对话。任务绑定发起会话；旧任务引用缺失时显示占位，不错配新任务。
- 分析团队：新增、编辑、复制、删除、启停专家；设置主视角与投票权重。
- 专家配置：名称、简介、岗位、方法来源、决策依据、已知缺陷、专属参数、模型、温度、输出长度、超时及只读工具权限。
- 团队编排：并行 / 顺序 / 讨论、等权 / 加权 / 全体一致、共识门槛、弃权、反方否决与证据要求。
- 任务配置：研究池、历史命中率、**覆盖率硬下限 10%**、H1–H20 范围及基本面 / 技术演示参数。
- 模拟任务：可见进度、取消、保存不可变配置与输入快照、查看记录、按原配置重跑；修改配置会标记旧结果过期。
- 研究清单与量化表：内嵌 6,244 个标的快照，类型 / 方向 / 文本筛选、排序、分页、详情、添加关注及 JSON 导出。
- 配置持久化：浏览器 localStorage；刷新恢复；JSON 导入 / 导出；损坏记录隔离、字段范围校验、未保存离开提醒。
- 快捷键：Ctrl / Command + K 搜索，Esc 关闭面板，Enter 发送（Shift + Enter 换行）；桌面与窄屏导航适配。

## 真实数据与模拟内容的边界

- **量化数字**来自已有 [全历史拟合数据](../../reports/fullfit/fullfit.json)，截止 2026-11-05，属于内样本命中率，并非校准后的未来概率。
- **基本面数字、价格结构图、专家意见**均为 4 个内置样本的本地演示，未调用模型、未查询真实财报。页面始终标识来源与限制。
- 设置研究范围为“全市场”会在量化表中筛选历史快照；模拟研究不会重新拟合 6,244 个标的，只演示最多 4 个内置样本。
- 模型、温度、输出长度、超时、讨论轮数和工具权限可保存，但不会触发在线推理或真实工具调用。不给出伪造的“连接成功”。
- 复制专家保留策略类型；新建的自定义自然语言框架不被当成可执行程序，默认观望。
- PE / 股息率、价格行为回看与目标 R、量化命中率门槛、权重、共识机制、弃权及否决会影响明确标注的模拟逻辑。
- 无 API 密钥输入、无券商接口、无交易执行。配置和记录仅保存在本机；换浏览器、移动文件或清理站点数据后可能不可见，请先导出备份。
